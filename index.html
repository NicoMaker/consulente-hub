Impossibile caricare i dati

Il browser ha bloccato la lettura di data.json. Succede quando la pagina viene aperta direttamente come file locale (file://) invece che da un server: per motivi di sicurezza, i browser impediscono a una pagina aperta così di leggere altri file sul disco.

Soluzione — avvia un piccolo server locale:

  1. Apri un terminale nella cartella del progetto
  2. Esegui: python3 -m http.server 8000
  3. Apri http://localhost:8000 nel browser
